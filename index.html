Deployment architecture

This Vercel site is a public landing page, not the always-connected WhatsApp bot. Keep the Baileys/WhatsApp connection running on an always-on host such as an EC2 instance, and use this site for onboarding, instructions, and branding.

WhatsApp ↔ MANUKA-MD (EC2 / always-on Node.js worker)
Visitors → MANUKA-MD Website (Vercel / static)
