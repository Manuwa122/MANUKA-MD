QR / Pairing Setup Guide

Connect your own WhatsApp account from your existing AWS EC2 bot worker.

Deploy the bot worker

Use an always-on Node.js server such as EC2. Install dependencies and configure the private environment file.

Start the process

Run it with PM2. If no saved WhatsApp session exists, the terminal displays a pairing QR code.

Link your account

On your phone, open WhatsApp → Linked devices → Link a device, then scan your terminal's QR code.

Keep session private

Never share screenshots of QR codes, auth folders, API keys or pairing/session tokens.

Useful EC2 commands

cd ~/MANUKA-MD
npm ci
npm test
npm run check
pm2 start src/index.js --name MANUKA-MD
pm2 save
pm2 logs MANUKA-MD --lines 30

Already running? Use pm2 restart MANUKA-MD --update-env instead of launching a second process.

This website intentionally does not collect QR codes or account credentials.

Hosting: Vercel + EC2

Professional public presence without breaking your always-connected WhatsApp bot.

Vercel hosts this website, not the persistent Baileys session. Keep MANUKA-MD running on AWS EC2 or another always-on Node.js host. Do not run two processes with the same WhatsApp session.
